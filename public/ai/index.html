No AI inside. Any AI outside.

FlywheelCAD has no cloud connection and no account. It doesn't need one: every document is ordinary Python, so the coding agent you already use can write and refactor your models.

  • The AI Scripting Guide is the whole API in one Markdown file, sized for a context window.
  • Drop it in, describe the part, and let the agent do the hard geometry — gear teeth, airfoil sections, part families.
  • Whatever it writes stays a .py file. Open it, run it, keep going by hand or by prompt.

How to use it

Claude Code

  1. Put FlywheelCAD-AI-Scripting-Guide.md in your project folder.
  2. Add one line to the project's CLAUDE.md: Before writing FlywheelCAD code, read FlywheelCAD-AI-Scripting-Guide.md.
  3. Describe the part: “Write main.py for a 60 × 40 mm plate with four M3 clearance holes, fully constrained, sizes as variables.”
  4. Open the result in FlywheelCAD. If it is already open, keep it open: the app watches main.py and picks up the agent's edits.

Cursor

  1. Add the guide under @Docs with its URL, https://flywheelcad.com/downloads/FlywheelCAD-AI-Scripting-Guide.md — or keep the file in the workspace.
  2. Mention it in the chat (@FlywheelCAD-AI-Scripting-Guide.md), or point a project rule at it so every chat reads it.
  3. Describe the part and let the agent write the .py file.
  4. Open the file in FlywheelCAD and carry on by hand or by prompt.

Any chat assistant

  1. Attach the guide to the conversation.
  2. Describe the part, and ask for one complete script.
  3. Save the reply as a .py file.
  4. Open it in FlywheelCAD. If a run fails, paste the error back; the guide tells the assistant what the messages mean.

A document is a program. The first time FlywheelCAD opens a script it has not seen before, it asks before running it. Expect that prompt for anything an agent generates, and read the script first if you did not write the request yourself.

It stays your model

What the agent writes is the same kind of file you get from clicking in the app. Constraints it adds show up in the sketch; dimensions it binds to variables appear in the Variables panel; a hole it places can be edited like any other. Change something in the GUI and the script updates — hand it back to the agent later and it reads your changes.

The guide covers the rules that are easy to get wrong: how regions are declared, which arguments take variables, how components and mates work, and what each error means. The Python syntax page is the human-oriented version of the same reference.
