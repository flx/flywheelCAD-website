How it works

One document, three ways in. The GUI and the Python are the same model; an agent edits it the way you would.

Sketch with constraints

Draw rough, then pin it: horizontal, vertical, tangent, equal, dimensions. The badge tells you when the sketch is fully constrained and which constraints conflict. Every constraint is one line of Python.

WIDTH = cad.variable(80.0, driving=True)
B = cad.point2d(WIDTH, 0.0)
cad.horizontal(l_bottom)
cad.distance(A, B, WIDTH)
hole = cad.circle2d(hc, HOLE_DIA / 2.0)

Edit the Python

The right panel is the model. Change a variable, run it, and the part re-solves. Helper modules sit next to the main file; a document is a plain .py or a .fwcad bundle that packages everything it imports.

> Add 4 holes to the bracket in
  Bracket.fwcad. The holes are at the
  4 outside edges of the bracket, have
  a diameter of 10mm and edge distance
  of 15mm. Drive the diameter and edge
  distance by fixed variables with the
  name "dia" and "dist".

Hand it to an agent, take it back

No built-in AI. Give the scripting guide to Claude Code, Cursor or any agent, describe the part, and it writes ordinary FlywheelCAD Python. Open the result, edit a dimension it wrote, and the part follows. (The prompt above is the one in the video.)

No AI inside. Any AI outside.

FlywheelCAD has no cloud connection and no account. It doesn't need one: every document is ordinary Python, so the coding agent you already use can write and refactor your models.

  • The AI Scripting Guide is the whole API in one Markdown file, sized for a context window.
  • Drop it in, describe the part, and let the agent do the hard geometry — gear teeth, airfoil sections, part families.
  • Whatever it writes stays a .py file. Open it, run it, keep going by hand or by prompt.
