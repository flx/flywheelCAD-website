What the beta does

  • Sketch and constrain — points, lines, arcs, circles, ellipses and splines, with geometric constraints, dimensions and shared variables. A badge shows when a sketch is fully constrained and which constraints conflict.
  • Build bodies — extrude, revolve, multi-section loft and sweep; booleans with an optional smooth or chamfered seam; edge rounding, draft and twist.
  • Compose assemblies — define a part once, instance it, and mate instances onto named anchor points.
  • Standard parts library — NEMA steppers, hobby servos, metric fasteners, bearings, gears, T-slot extrusion and more, inserted with a live preview.
  • Export — bodies to 3MF, STL, OBJ and glTF (.glb, .gltf), with per-body colours and finishes where the format carries them; sketches to DXF and SVG.
  • Bring your own AI — every document is ordinary Python, so any coding agent can write and refactor your models. See the AI page.

Known limits

  • No STEP export. FlywheelCAD builds meshes from signed distance fields — the same class of kernel as OpenSCAD — not boundary representations.
  • No 2D drawing sheets. Sketches export as DXF and SVG.
  • macOS on Apple silicon only.
  • It is a beta: report problems on GitHub.
